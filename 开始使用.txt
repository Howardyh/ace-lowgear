ACE LowGear · 开始使用

1. 将源码 ZIP 完整解压到普通文件夹，双击“开始使用.cmd”或 Start.cmd。
2. 允许 Windows 管理员提示。首次安装按向导介绍、检查、确认后启用。
3. 可以先查看面板；选择会记住，之后从概览点击“启用自动管理”重新进入。

已有安装：打开本版本入口，点击“升级本机组件”。升级保留启用/暂停状态、相关性和最早原始备份。
日常使用：启用后可以关闭窗口。重启电脑后无需重复安装，照常启动游戏即可。
首次核验：正常启动游戏后等待约 45 秒，再刷新状态。自动执行已配置与实际进程已核验是不同结果。
暂停或恢复：在“设置”管理自动执行；暂停不删除原始备份。
撤回修改：“设置 → 完整恢复原设置”，确认后恢复最早原值；原始备份继续保留。

启动未完成时请查看中文提示。缺少文件请重新下载并完整解压；取消授权后可按需要重新打开。
发布页的源码 ZIP 是推荐下载；.sha256 是校验文件，无需运行。GitHub 自动生成的 Source code 归档是仓库快照。
不需要安装 Python、Node.js 或 .NET SDK。请勿把本机运行资料和原始备份复制到其他电脑。
