# 验证方法与范围

运行 `tests/Run.ps1`，默认在唯一命名的 HKCU 沙盒和临时目录中测试。安装事务使用内存任务与事件适配器，避免修改真实任务；Native 调度与会话测试使用自建、随机命名的临时程序。生产目标不会被伪装成测试程序。

测试包含原值不存在、多种值类型及空值的 JSON 往返恢复、无关值保留、无关程序名拒绝、安装中任务注册失败后的注册表回滚、原始恢复记录、损坏与异机备份拒绝、后续修改冲突检测、CPU 与 I/O 实际回读、最后逻辑 CPU 绑定、会话完成后退出、退出后不再纠正、换 PID 后新会话、无关进程保留和最近执行记录。

管理员 Windows PowerShell 会话增加 `-StartupProbe`，用随机测试程序在真实 IFEO 中验证正常基线和两次最低优先级启动，再验证测试键与文件清理。它不会写入真实 ACE 的注册表键。

增加 `-UiPreview` 并指定本地 PNG 路径，可构建整个 WPF 面板、检查命名控件并渲染演示数据。演示画面不代表实际 ACE 检查结果。

管理员运行 `tests/Event.ps1`，对随机命名临时程序建立真实 WMI 事件与计划任务，验证自动触发、完成退出、退出后不持续纠正、再次启动触发新会话，以及任务和事件对象精确清理。这个测试不会重命名为 ACE，也不会修改实际 ACE 设置。

部署验收另行记录：旧原始备份迁移、旧常驻任务移除、新任务 SYSTEM 身份、真实进程启动事件、无开机/登录/定期触发、单实例、2 分钟任务时间上限、原生程序 hash、会话退出和暂停/恢复生命周期。

1.0.0 曾收到单台电脑重启后实际 ACE 核验通过的用户反馈。此项与新版验收、自动测试分别记录；不公开原始报告、机器标识、PID 或个人目录。旧版读值不作为 1.1 的验收依据。

游戏长时间使用、其他硬件、其他 Windows 与游戏版本仍需分别接受测试。公共 CI 也不能替代目标电脑的真实游戏验证。

## 1.1 新增验证

`tests/Upgrade.ps1` 使用随机 HKCU 和文件沙盒，验证 1.0.0 格式兼容、保留暂停和相关性、幂等升级、注册/启动失败回滚、未完成事务恢复、拒绝外部修改、查询失败隔离、旧会话拒绝、实例变化、运行失败与脱敏摘要。

`tests/Panel.ps1` 直接测试本项目 WPF 控件和只读执行线程，注入慢查询与失败查询，验证无重叠、5/30 秒刷新选择、关闭保护、重复操作和 100%/125%/150%/200% 渲染。渲染与组件检查不等同于所有屏幕和机器上的人工验收。

本地 1.1 检查共 126 项通过：`Run.ps1 -StartupProbe -UiPreview <本地 PNG 路径>` 65 项、`Upgrade.ps1` 36 项、`Panel.ps1` 20 项、`Event.ps1` 5 项。公共 CI 的主测试未指定 `-UiPreview`，少一项单独预览文件检查；面板测试仍覆盖四档缩放渲染。

- 任务、事件配置和执行文件完整性检查通过。验收脚本已退出，不留下持续查询或纠错程序。

此项验证单机正常游戏启动，未做 1.1 整机重启、长时间游戏或主动提高真实 ACE 优先级的实验。再次启动产生新会话、结束后不持续纠正和恢复到最早原值由独立测试覆盖。实际验收报告与恢复资料仅留在本地，不随源码发布。
