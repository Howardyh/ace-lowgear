# 隐私与公开范围

项目运行不需要网络、账户、密码或 API 凭据，没有遥测或自动上传。

公开材料仅包含 `public-files.json` 中的源码、界面定义、文档和测试。运行程序从源码在本机编译，不把生成的 EXE、备份、状态、日志、截图、PID 或安装报告加入仓库。

运行数据仅保存到本机通用数据目录。Windows 安装标识先加固定领域前缀计算 SHA-256，原始标识不写入恢复记录。最近会话记录包含目标程序名、PID、调度读值、错误原因及时间；它属于本机资料。操作系统错误可能带本地路径，分享报告前应审阅。

本机数据目录只允许管理员和 SYSTEM 写入，普通用户可读取。提交和打包前扫描允许公开的文件，识别个人 Windows 路径、邮箱、凭据格式、私钥、本地账户 SID 和当前账户/计算机名。自动扫描并非完整隐私证明，还要人工检查文件清单、Git 作者邮箱和归档内容。

发布应使用 GitHub noreply 邮箱，先让项目所有者审核，再上传源码。开发中的运行报告、用户粘贴内容与原始备份都不属于公开清单。

## 1.1 诊断摘要

原始状态 JSON 与会话记录仍是本机资料。Diagnose 和面板的“诊断摘要”使用独立字段白名单，只输出软件版本、Windows 版本、处理器数量、配置状态和规范错误码；不复制原始异常文本、个人路径、PID、安装摘要或原始备份。面板先预览再由用户主动复制，不自动发送。
