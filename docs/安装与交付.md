# 安装与交付

本包使用系统自带 Windows PowerShell 5.1、WPF 和 .NET Framework，不要求用户另装 SDK。

## 从启动到安装

中文入口与 Start.cmd 调用同一个 PowerShell 启动器，主入口不依赖 VBS。旧 VBS 入口兼容保留。
启动器检查公开清单和必需源码；文档或测试缺失只警告，运行文件缺失会停止并解释如何完整解压。完整源码放在临时目录也能运行，不按目录名称猜测用户是否正在压缩包中启动。

系统管理员授权完成后，启动器等待受保护临时目录中的就绪回执，最多 90 秒。界面就绪后启动器退出；初始化失败、取消授权、提前退出或超时会给出中文提示。超时不杀掉原进程，也不自动启动第二份。只有当前用户、管理员和 SYSTEM 可以访问回执目录；清理仅删除已知回执，不递归清理未知文件。

首次向导依次展示介绍与策略、检查与确认、执行、结果。下一步预检是只读操作；最终确认安装后才保存原始设置并进行真实启动自检。旧版迁移和无损升级继续调用同一个控制器，不绕过归属、备份和冲突校验。

“先查看面板”会记住。已有安装和暂停状态直接进入面板，读取失败和未完成事务进入诊断。概览可手动重新进入安装向导；升级显示当前/目标版本及保留状态，恢复仍需要单独确认。

## 结果与恢复

结果页分别表达配置完成、等待游戏启动和当前运行实例已核验。NoTargets 表示没有运行目标，不是实际游戏验收。升级前已暂停的安装继续暂停。恢复结果说明任务和事件已移除、最早原值已恢复、备份保留；已运行 ACE 请正常重启后核验。

点击“打开本机备份目录”仅在本机打开资料，不复制或上传。备份不随用户切换外观、暂缓安装或软件升级而删除。修改进行中暂缓关闭；操作还在等待只读查询时允许取消等待。

## 只读预检

`LowGear.ps1 -Command Preflight -Json` 返回既有 Success、Message、Detail、Report 结构。Detail 包含 Passed、Migration 和 Checks；检查项使用 Name、State、Code、Message。通过退出 0，阻断退出 1；现有命令退出码不变。

预检不会建立本机运行目录、原始备份、任务或启动规则。它会读取系统状态并在临时环境中加载本项目原生代码。查询失败不当作缺省配置成功；旧版资料冲突停止安装建议。运行时缺失等已安装异常仍由诊断、手动修复与恢复入口处理。

## 冻结交付

候选包和正式包使用同一份冻结源码、版本和归档哈希。包内说明不依赖“候选/正式”阶段，也不预先宣称机器或用户验收通过；发布状态、额外验收和推荐下载由发布页说明。只有公共清单内的源码、文档和测试进入包，原始资料、窗口偏好、回执、日志和图片保留在本机。

发布前执行源码与隐私检查、包内清单及逐文件哈希核对。界面体验通过后再安排发布，并核对正确提交的 CI、公开访问和匿名下载哈希。历史版本与原始恢复资料保留。
