# 迁移与恢复

新版与 0.1.x 是独立项目。迁移前请保留旧源码、原始备份和状态目录。新版不会删除这些资料，也不会修改游戏二进制。

迁移验证旧版活动记录的 schema、Windows 安装摘要、原始备份 SHA-256 和固定目标列表，确认旧版当前启动值符合管理值。导入的是旧版第一次修改前的原值，之后新版恢复仍能回到该起点。

安装事务先保存备份与 Installing 记录，再停止旧任务、写入启动规则、创建启动事件订阅与新版一次性任务。任务必须实际运行并产生执行记录，才能完成 Active 状态。Active 表示触发配置已启用；最近会话是否完成、当前实例是否达标会单独显示。失败尝试恢复本次安装前的值及旧任务，完整回滚后归档失败记录；不完整时保留 RecoveryRequired，禁止盲目重复安装。

原始备份不可覆盖。恢复前核验原值归属、备份 hash 和后续修改冲突，然后移除启动事件、停止并删除新版任务，再逐值恢复。原本不存在的值会删除，只删除本工具创建且仍为空的键；无关值与子键保留。恢复记录与原始备份留存。

暂停移除启动事件、禁用并停止任务，启动规则仍存在。恢复自动执行会验证运行文件的 SHA-256，再注册事件、启用任务并执行一次。完整恢复后，当前进程的调度状态可能保持已有值，正常重启目标程序才会使用原始启动设置。

旧版任务成功迁移后不再运行。为避免新旧工具相互干扰，请统一使用新版入口。完整恢复不会重新启用旧版纠正任务。旧目录仅作为归档与故障恢复资料。

源代码目录移动不影响自动触发；任务使用受保护的本机运行副本。不要把 `%ProgramData%\ACE-LowGear` 复制到另一台电脑。重装 Windows 后，即使用户名相同，也应视为新的安装归属。

## 1.1 本机组件升级

升级在原数据目录内新建独立版本的执行目录，旧执行文件保留。切换前保存部署事务记录及校验值，再切换任务；原始备份引用和文件内容不变。重复升级到同版本不再次编译或部署。安装记录可读取 1.0.0 格式，但运行目录必须与安装版本一致。

Upgrade 保留启用或暂停状态；Install 明确安装并启用。升级或恢复自动执行失败时尝试回退之前的组件、策略和事件配置。中途被终止会留下未完成记录，Repair 可核验并撤回该事务。旧运行文件、事务记录或原始备份无法核验时停止覆盖，保留资料并提供原因。

Repair 不重写启动优先级，不重置用户策略，也不覆盖被其他工具修改的任务或事件。完整恢复仍回到最早原值。不要删除本机数据目录或在新旧入口之间交替修改；旧版入口不识别新运行目录，请统一使用当前版本。
