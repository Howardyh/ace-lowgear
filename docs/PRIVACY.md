# 隐私与公开范围

运行工具不需要网络、GitHub 登录、密码或 API 凭据，也没有遥测与自动上传功能。

## 源码与运行数据

公开源码仅由 `public-files.json` 的文件清单组成。打包工具依照该清单创建 ZIP，并比较文件名和每个文件的 SHA-256。`.gitignore` 同时排除运行数据、备份、报告、转储与二进制文件。

本机数据放在 `%ProgramData%\ACE-LowGear`：原始注册表值、恢复记录、操作报告和一个 Windows 安装标识的 SHA-256 摘要。原始安装标识不会写入备份。数据目录允许管理员和 SYSTEM 写入，普通本地用户读取。它不应复制到其他电脑，也不应提交到仓库。

报告可能包含进程 ID、处理器数量、时间和读取错误；系统错误有时包含本地路径。发布问题报告前请自行审阅，优先描述状态和错误类型，避免直接上传整个本地数据目录。

## 发布前检查

`tools/Test-PublicContent.ps1` 检查允许公开的文件，识别个人 Windows 路径、常见 GitHub 凭据、私钥、个人邮箱、本地用户 SID 和当前账户/计算机名称。输出只包含文件名与问题类型，不回显匹配的敏感值。`-CheckIndex` 还检查 Git 暂存区文件清单及暂存内容。

自动扫描需要配合人工审阅：检查源码、文档、ZIP 文件清单和 Git 作者信息。Git 提交作者与邮箱会公开，发布时应使用 GitHub 的 noreply 邮箱；不将个人邮箱写入项目配置。

源码中允许出现系统通用路径、内置安全主体 SID 和官方文档链接。用户名、个人目录、主机名、真实安装报告与备份均不属于公开材料。
